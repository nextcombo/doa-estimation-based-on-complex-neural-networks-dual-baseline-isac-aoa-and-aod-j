# DOA Estimation Based on Complex Neural Networks: Dual-Baseline ISAC AoA and AoD Joint Estimation [Attached Code]

Introduction In this work, we investigate the parameter estimation within a dual-baseline radar setup within an ISAC system, focusing on estimating the Angle of Arrival (AoA) and Angle of Departure (AoD). Since maximum likelihood estimation is a highly multidimensional optimization problem that is not feasible for real-time implementation with actual hardware resources, we propose to leverage the capabilities of neural networks (NN) for generalized approximations, performing this complex estimation task with low complexity optimization NN architectures. In [17], the AoA and AoD estimation problems are either framed as regression problems [18] or as spectral-based sensing estimations [20] [21], where NNs are trained on thermally encoded ground truth vectors representing discrete grids with a given base, minimizing the target function such as Mean Square Error (MSE) between estimated and true angles. In the latter case, the network does not rely on prior knowledge of the number of targets. Instead, it is trained to output the spectrum of estimated angles, which then requires additional steps for target detection from peak extraction, as typically done in conventional methods like MUSIC. Other DL approaches have been proposed, such as multi-task autoencoders and a series of parallel multilayer classifiers [22]. In our study, we propose a novel method to address the problem of using different inputs for perception estimation and training a complex value NN to minimize the MSE objective function on a training dataset generated using an ideal system model. Furthermore, we present a parameterized algorithm that utilizes knowledge models for benchmark testing. Specifically, the parameterized two-dimensional approach estimates the AoA and AoD targets utilizing all knowledge of array steering vectors and OFDM subcarrier regular structure. Although OFDM is assumed in the model, our work remains valid for any pre-coded OFDM modulation, such as Discrete Fourier Transform (DFT) extended OFDM. To compare, Cramer-Rao bounds (CRB) are also shown. The results indicate that the DL-based solution provides comparable estimation performance with a parameterized approach, requiring minimal computational effort.
This paper presents the main contributions as follows:
1.1 A novel joint AoA/AoD DL estimator. We introduce a new DL technique for parameter estimation in ISAC systems, namely AoA and AoD. Starting from traditional input sources, this method leverages an estimated channel matrix using complex-valued neural networks, which captures essential information about the sensed parameters. The DL model employs complex-valued convolutional layers and linear layers with weight representations as complex matrices, enhancing the model's ability to accurately represent the channel matrix. The activation function is chosen as the complex-valued relu (CReLU). The network structure includes three hidden layers and a final output layer for predicting the sensed parameters. Additionally, MSE is used as the objective function during training.
1.2 A novel design of parameterized AoA/AoD estimator. We develop a parameterized approach for AoA/AoD estimation that leverages complete model knowledge, including the geometric shape of the array. This method involves transforming the received channel matrix into a smaller channel matrix with a given subarray size by utilizing uniform linear antenna (MIMO) structures on both the transmitter and receiver sides. The method further calculates certain eigenvalues using induced Hankel structures, which aids in AoD estimation. For AoA estimation, least squares (LS) fitting is required at a later stage of the algorithm.
Furthermore, we reveal some important insights:
1.3 Through simulations, we investigate the impact of training SNR on the achieved MSE performance. Specifically, using simulated data generated under specific SNR values to train an MLP architecture, and evaluating the network's performance on a test dataset spanning a range of given SNR values. We observe a steady decline in loss curves during training, indicating effective learning and generalization to unseen data. Regarding overfitting, we employ a learning rate schedule. Additionally, we present various simulation results demonstrating the superior performance and potential of the proposed method compared to others, as well as its closeness to the CRB benchmark.
· We conducted a comprehensive computational complexity analysis for both methods, focusing on the total number of multiplications and additions required to implement them. This analysis included a detailed examination of the complexity associated with DL techniques, which employ architectures with three hidden layers and assessed the complexity involved in different operations through computation. Additionally, for parametric approaches, we provided breakdowns of computational complexity associated with specific blocks, such as channel estimation, coarse timing estimation, and sensor estimation. This included highlighting estimation overheads and detailing the total number of operations per block. We also proposed an estimation problem for maximum likelihood criteria, emphasizing significant reductions in complexity compared to maximum likelihood estimation (MLE) for these two methods. Moreover, our simulations indicate that the recommended DL technique offers lower computational complexity for the parameterized 2D estimation process compared to the suggested DL technology. For example, for 8 receive antennas, the 2D algorithm requires 6.5 times more multiplication than the DL algorithm, which is 15.27% of the computational complexity required for multiplication by the 2D algorithm for its intended purpose. Despite performance degradation, especially at higher SNR values, these results underscore the significant percentage increase in computational efficiency and scalability offered by DL designs.
· The study investigated the impact of antenna pattern on the performance of dual-base station ISAC systems. After incorporating these patterns into our system model, we will explore how changes in their parameters affect CRB. Our analysis indicates that narrower, more focused beams require higher SNR to achieve the desired CRB target for sensor applications. This insight highlights the complex interplay between antenna design choices and ISAC system performance, emphasizing the importance of integrating radiation pattern characteristics to improve sensor accuracy in practical applications.
